
EEG Alpha and Beta Frequency Analysis Using Python

Overview:
This project analyzes an EEG signal using basic frequency-domain signal processing techniques in Python and Google Colab.
The project focuses on estimating the power of two common EEG frequency bands:
- Alpha: 8–13 Hz
- Beta: 13–30 Hz

Dataset:
The project uses the EEG Eye State dataset from the UCI Machine Learning Repository, accessed through DataHub.
Dataset:
https://datahub.io/core/eeg-eye-state
